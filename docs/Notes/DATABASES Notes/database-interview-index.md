## Suggested Study Order

1. SQL fundamentals: joins, indexes, transactions, normalization
2. PostgreSQL: practical relational administration and tuning
3. SQL query problems
4. Real-time interview questions and live scenario-based query rounds
5. MongoDB: documents, aggregation, schema flexibility, indexing
6. Cassandra: partitioning, replication, consistency, query-driven design
7. Solr: indexing, schema, analyzers, faceting, querying
8. Senior production guide
