## Recommended Study Order

1. Revise core syntax, OOP, collections, exceptions, strings, and Java 8 basics from [course-notes](./course-notes/README.md).
2. Study core runtime topics from [runtime-internals](./runtime-internals/).
3. Practice structured answers from `interview-prep`.
4. Practice solved coding from `interview-prep`, then unsolved banks from `coding`.
5. Use `interview-guides` for deeper topic-based revision.
6. Revise Java 11, 17, 21, and 25 changes from [version-notes](./version-notes/).

## Interview Strategy

- Beginner interviews usually test syntax, collections, OOP, and basic Java 8 usage.
- Intermediate interviews test design choices, collections internals, exception strategy, concurrency reasoning, and API usage.
- 4 to 6 year interviews often test architecture, tradeoffs, debugging, GC or runtime thinking, and modernization strategy.
- Use [Java core internals interview questions](./runtime-internals/java-core-internals-interview-questions.md) to strengthen JVM, memory, GC, and concurrency answers that are often missed in normal Java revision.
- Use [Java coding questions with solutions](./interview-prep/java-coding-questions-with-solutions.md) for core hands-on problem-solving.
- Use [Java coding questions: advanced patterns with solutions](./interview-prep/java-coding-questions-advanced-patterns-with-solutions.md) for structured algorithms practice.
- Use [Java coding banks](./coding/README.md) for raw practice without immediate answers.
