## Recommended Learning Order

1. Start with [course-notes/java-index.md](./course-notes/java-index.md) for fundamentals through enterprise Java.
2. Use [learning-guides/java-8-11-17-21-25-complete-learning-notes.md](./learning-guides/java-8-11-17-21-25-complete-learning-notes.md) for upgrade-focused revision.
3. Read [version-notes](./version-notes/) when you want release-specific additions, removals, and migration impact.
4. Use [runtime-internals/java-core-internals-and-runtime-deep-notes.md](./runtime-internals/java-core-internals-and-runtime-deep-notes.md) for JVM, memory, GC, and concurrency depth.
5. Practice spoken answers from [interview-prep](./interview-prep/) and deeper topic revision from [interview-guides](./interview-guides/README.md).
6. Use [coding](./coding/README.md) plus the solved coding files under [interview-prep](./interview-prep/) for problem-solving practice.

## Directory Map

- `course-notes/`: complete numbered Java learning course from basics to projects
- `learning-guides/`: cross-version summaries and migration learning notes
- `version-notes/`: Java 8, 11, 17, 21, 25 detailed notes
- `runtime-internals/`: JVM internals and deep runtime interview notes
- `interview-prep/`: beginner to experienced interview questions with short and better answers
- `interview-guides/`: topic-by-topic deep interview material and senior-level question banks
- `coding/`: raw coding interview problem banks

## Best Use

- Use `course-notes` when learning Java sequentially.
- Use `version-notes` and `learning-guides` when preparing for migration or modernization discussions.
- Use `runtime-internals` and `interview-guides` when preparing for 4 to 7 year Java backend rounds.
- Use `interview-prep` when you want polished, interviewer-friendly answer formats.
