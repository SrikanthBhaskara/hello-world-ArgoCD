# Quick Revision Checklist

## Core concepts to revise
- Can I explain why Java 8 mattered historically and practically?
- Can I explain lambdas and functional interfaces clearly?
- Can I distinguish Predicate, Function, Consumer, and Supplier?
- Can I explain streams, laziness, and pipeline structure?
- Can I explain `filter`, `map`, `flatMap`, `collect`, and `reduce`?
- Can I explain Optional and common misuse?
- Can I explain default methods and interface evolution?
- Can I explain why `java.time` replaced old date APIs?
- Can I explain parallel stream tradeoffs?
- Can I explain CompletableFuture basics?

## Final prep questions
- Can I explain each concept with one code example?
- Can I explain one misuse or tradeoff for each major feature?
- Can I compare Java 7 style and Java 8 style clearly?
- Can I answer practical interview questions without only reciting definitions?

## Final speaking readiness check
- Can I explain why Java 8 features were introduced?
- Can I explain not only syntax but also engineering value?
- Can I answer what to use, when to use it, and when not to use it?

## Final code readiness check
- Can I write one lambda from memory?
- Can I write a stream pipeline with `filter`, `map`, and `collect`?
- Can I write an Optional chain safely?
- Can I explain a CompletableFuture chain using `thenApply` and `thenCompose`?
