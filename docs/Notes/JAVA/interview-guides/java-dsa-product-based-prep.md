# Product-Based Company Java DSA Prep

## What To Expect

Product-based company coding rounds usually expect:
- solid medium-level DSA by default
- some hard follow-ups or harder medium variants
- strong pattern recognition
- clear tradeoff explanation
- better coding discipline under time pressure

## Highest-Priority Topics

- arrays and strings
- hashing
- sliding window
- binary search
- intervals
- heap and top-k
- linked list
- trees and BST
- graphs
- backtracking
- dynamic programming

## Java Focus Areas

- write helper methods clearly
- choose correct collection quickly
- use recursion carefully
- manage visited sets and state properly
- keep complexity explanation sharp

## Interview Strategy

1. identify the pattern early
2. explain brute-force briefly
3. move to optimized solution with confidence
4. code in clean Java with minimal noise
5. mention complexity and discuss edge cases before being asked

## What Product Companies Often Evaluate Beyond Correctness

- how fast you recognize patterns
- whether you can improve a valid but weak solution
- whether your code is maintainable and testable
- whether you can discuss alternatives

## Best Practice Plan

- 25 easy for speed and confidence
- 50 medium for pattern depth
- 15 hard or advanced follow-up problems
- timed rounds with 1 medium plus 1 easy or 2 mediums

## Strong Interview Lines

- "This pattern is essentially sliding window because the subarray is contiguous and the left boundary only needs to move forward."
- "A heap is more efficient here because we need repeated top-k retrieval rather than a one-time full ordering."
- "This recursion has overlapping subproblems, so dynamic programming is the next improvement."
