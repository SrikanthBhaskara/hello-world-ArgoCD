# Java Company-Wise DSA Interview Prep

## Purpose

This file organizes Java coding-round preparation by company style instead of only by topic.

Use it for:
- adjusting practice by company type
- knowing what level of DSA depth to expect
- choosing the right problem mix before interviews

## How To Use

1. Pick the company style closest to your target.
2. Revise the recommended patterns and problem types.
3. Practice under time pressure using Java.
4. Explain brute-force, optimized solution, and complexity clearly.
5. Revisit weak areas after each mock round.

## Quick Guidance

### Amazon-style
- strong medium-level DSA
- clear optimization thinking
- follow-up improvements matter a lot
- often expects practical coding speed

### Cisco-style
- balanced Java plus DSA plus backend thinking
- clean coding, collections, strings, concurrency basics, debugging
- moderate DSA depth with practical reasoning

### Service-based companies
- easier to medium coding rounds
- strong basics matter a lot
- consistency often matters more than rare hard problems

### Product-based companies
- medium to hard DSA more common
- deeper pattern recognition expected
- code quality and optimization both matter
