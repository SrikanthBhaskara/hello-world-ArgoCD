# Frontend Interview Questions: Beginner 0 to 2 Years

## HTML and CSS
1. What is semantic HTML and why is it useful?
2. What is the box model?
3. What is the difference between block and inline elements?
4. What is responsive design?
5. What is the difference between `display: none` and `visibility: hidden`?

## JavaScript Basics
6. What is the difference between `var`, `let`, and `const`?
7. What is a closure?
8. What is the event loop at a basic level?
9. What is the difference between `==` and `===`?
10. What are promises?

## Browser Basics
11. What is the difference between cookies, localStorage, and sessionStorage?
12. What is CORS at a high level?
13. What is caching in the browser?

## React Basics
14. What is a component?
15. What is the difference between props and state?
16. What is `useState` used for?
17. What does `useEffect` do?
18. Why are keys needed in lists?
19. What is conditional rendering?
20. What is lifting state up?

## What to Focus On
- basic rendering
- component communication
- state and props
- browser fundamentals
- simple API handling
