# Frontend Interview Questions: Beginner to 6 Years

## 0 to 2 Years

### HTML, CSS, and Browser Basics
1. What is semantic HTML and why is it important?
2. What is the difference between `id` and `class`?
3. What is the box model?
4. What is the difference between `display: none` and `visibility: hidden`?
5. What is responsive design?
6. What is CORS at a high level?
7. What is the difference between cookies, localStorage, and sessionStorage?

### JavaScript Basics
8. What is the difference between `var`, `let`, and `const`?
9. What is a closure?
10. What is the event loop?
11. What is the difference between `==` and `===`?
12. What are promises and why are they used?
13. What is the difference between synchronous and asynchronous code?

### React Basics
14. What is a component?
15. What is the difference between props and state?
16. What is a hook?
17. What does `useEffect` do?
18. Why do lists need keys in React?
19. What is conditional rendering?
20. What is lifting state up?

## 2 to 4 Years

### React and Frontend Engineering
1. When would you use `useReducer` instead of `useState`?
2. What causes unnecessary re-renders in React?
3. What is memoization in React and when is it useful?
4. What is the difference between controlled and uncontrolled components?
5. How would you structure a medium-sized React application?
6. What is code splitting and why does it matter?
7. What is the difference between client-side rendering and server-side rendering?
8. How would you handle loading, empty, and error states in a UI?

### API and Data Handling
9. How do you handle API failures in the frontend?
10. How do you avoid race conditions in search or filter requests?
11. What is optimistic UI update?
12. What is pagination and when would you prefer cursor-based pagination?

### Testing and Quality
13. What is the difference between unit, component, and end-to-end tests?
14. Why is React Testing Library generally preferred over implementation-detail-heavy testing?
15. What would you test in a login form?

## 4 to 6 Years

### Architecture and Performance
1. How do you decide between SSR, CSR, SSG, and ISR?
2. How do you design frontend state management for a large application?
3. What is hydration and what problems can occur around it?
4. How would you investigate a slow React page?
5. What is bundle analysis and what kinds of issues does it help uncover?
6. How would you reduce initial page load time?

### Security and Reliability
7. How do you defend against XSS in a frontend application?
8. When does CSRF matter and when does it matter less?
9. What are the risks of storing auth tokens in localStorage?
10. How would you design frontend auth for a multi-tenant application?

### Full-Stack and Production Thinking
11. How would you handle schema changes when frontend and backend evolve independently?
12. How do feature flags help frontend delivery?
13. What telemetry would you add to a business-critical frontend flow?
14. How do you debug a production-only issue that cannot be reproduced locally?
15. When would you choose WebSocket, SSE, REST, or GraphQL for frontend data access?

## 5 to 6+ Years Follow-Up Themes
- architecture tradeoffs
- production debugging
- UX under failure
- performance budgets
- accessibility ownership
- release safety
- observability and tracing
- frontend and backend contract evolution

## How To Use This File
- Use the 0 to 2 year section for fundamentals.
- Use the 2 to 4 year section to practice implementation and design questions.
- Use the 4 to 6 year section for architecture, security, and production-oriented answers.
- Convert the most important questions into spoken answers before interviews.
