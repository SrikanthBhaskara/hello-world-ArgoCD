# Frontend Interview Questions: Experienced 4 to 6 Years

## Architecture
1. How do you choose between CSR, SSR, SSG, and ISR?
2. How do you design state management for a large application?
3. What is hydration and what problems can occur around it?
4. When would you choose GraphQL, REST, SSE, or WebSocket for frontend data access?

## Performance
5. How would you investigate a slow React page?
6. What is bundle analysis and why does it matter?
7. How would you reduce initial page load time?
8. How would you handle rendering large lists?

## Reliability and Operations
9. How do you debug a production-only frontend issue?
10. How do feature flags help frontend delivery?
11. What telemetry would you add to a critical user journey?
12. How do you handle stale assets or cache issues after deployment?

## Security
13. How do you defend against XSS in a real application?
14. How do you think about auth token storage and browser security tradeoffs?
15. How would you design frontend auth for a multi-tenant system?

## Full-Stack Coordination
16. How do you handle schema or contract changes between frontend and backend?
17. How do you work with backend teams on API shape and rollout?
18. What changes in expectations as you move toward senior full-stack ownership?

## What to Focus On
- tradeoff-based answers
- production debugging
- release safety
- frontend-backend contract thinking
