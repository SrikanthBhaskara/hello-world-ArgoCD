# Frontend Interview Questions: Intermediate 2 to 4 Years

## React Engineering
1. When would you use `useReducer` instead of `useState`?
2. What causes unnecessary re-renders?
3. What is memoization and when is it useful?
4. What is the difference between controlled and uncontrolled components?
5. How do you structure a medium-sized React application?

## Rendering and Data
6. What is code splitting?
7. What is the difference between client-side rendering and server-side rendering?
8. How do you handle loading, empty, and error states?
9. What is optimistic UI?
10. How do you handle API failures in the frontend?
11. How do you avoid race conditions in search or filter requests?
12. When would you use pagination?

## Testing
13. What is the difference between unit, component, and end-to-end tests?
14. Why is React Testing Library commonly preferred for UI behavior tests?
15. What should be tested in a login form?

## Security and Browser Behavior
16. What is XSS at a practical level?
17. When does CSRF matter?
18. What are risks of storing tokens in localStorage?

## What to Focus On
- building maintainable screens
- handling API and UI state cleanly
- understanding render behavior
- writing useful tests
