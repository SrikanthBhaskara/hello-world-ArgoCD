## Recommended Study Path

1. Start with Java, Linux, Git, REST API, Spring Boot, and frontend or full-stack basics.
2. Move to Docker, Kubernetes, ArgoCD, GitOps, and AWS.
3. Revise database, testing, microservices, system design, authentication, and observability material.
4. Finish with interview support files and mock rounds.
