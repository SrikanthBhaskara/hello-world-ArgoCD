## 1. Debian/Ubuntu Package Management (apt/dpkg) In-Depth

### 1.1 apt vs apt-get vs aptitude

| Tool | Purpose | When to Use |
|------|---------|-------------|
| **apt** | Modern, user-friendly CLI | Interactive use (recommended) |
| **apt-get** | Traditional, stable CLI | Scripts, older systems |
| **aptitude** | TUI + CLI, better dependency resolution | Complex dependency issues |
| **dpkg** | Low-level package tool | Direct .deb manipulation |

### 1.2 Advanced apt Operations

**Search and info:**\n```bash\n# Search package names and descriptions\napt search keyword\napt search --names-only keyword\n\n# Package information\napt show package-name\napt-cache policy package-name       # available versions\napt-cache showpkg package-name      # detailed dependency info\n\n# Reverse dependencies (what depends on this)\napt-cache rdepends package-name\n\n# List files in package\ndpkg -L package-name\n\n# Find which package owns a file\ndpkg -S /path/to/file\n```\n\n**Installation variants:**\n```bash\n# Install without recommended packages\nsudo apt install --no-install-recommends package-name\n\n# Reinstall broken package\nsudo apt install --reinstall package-name\n\n# Download package without installing\napt download package-name           # gets .deb file\n\n# Install local .deb file\nsudo apt install ./package.deb      # resolves dependencies\nsudo dpkg -i package.deb            # doesn't resolve dependencies\n```\n\n**Upgrade strategies:**\n```bash\n# Update package lists\nsudo apt update\n\n# Upgrade all packages (keeps current release)\nsudo apt upgrade\n\n# Upgrade + install new dependencies or remove conflicting ones\nsudo apt full-upgrade\n\n# Upgrade to new distribution release\nsudo do-release-upgrade\n```\n\n**Cleaning:**\n```bash\n# Remove package but keep config files\nsudo apt remove package-name\n\n# Remove package and config files\nsudo apt purge package-name\n\n# Remove automatically installed dependencies no longer needed\nsudo apt autoremove\n\n# Clean package cache\nsudo apt clean                      # remove all cached .deb files\nsudo apt autoclean                  # remove old cached .deb files\n```\n\n**Holds (prevent upgrades):**\n```bash\n# Hold package at current version\nsudo apt-mark hold package-name\n\n# Unhold\nsudo apt-mark unhold package-name\n\n# List held packages\napt-mark showhold\n```\n\n### 1.3 Repository Management\n\n**List repositories:**\n```bash\ncat /etc/apt/sources.list\nls /etc/apt/sources.list.d/\n```\n\n**Add repository:**\n```bash\n# Modern way (Ubuntu/Debian recent versions)\nsudo add-apt-repository ppa:user/ppa-name\nsudo apt update\n\n# Manual way - add to sources.list\necho \"deb http://repo.example.com/ubuntu focal main\" | \\\n  sudo tee /etc/apt/sources.list.d/example.list\n\n# Add repository key\nwget -qO- https://repo.example.com/key.gpg | sudo apt-key add -\n# Or modern way:\ncurl -fsSL https://repo.example.com/key.gpg | sudo gpg --dearmor -o /etc/apt/trusted.gpg.d/example.gpg\n```\n\n**Remove repository:**\n```bash\nsudo add-apt-repository --remove ppa:user/ppa-name\n# Or delete file:\nsudo rm /etc/apt/sources.list.d/example.list\n```\n\n### 1.4 dpkg Detailed Usage\n\n```bash\n# List all installed packages\ndpkg -l\ndpkg -l | grep package-name\n\n# Package status\ndpkg -s package-name\n\n# List files in installed package\ndpkg -L package-name\n\n# Find package that owns file\ndpkg -S /bin/ls\n\n# Extract .deb without installing\ndpkg -x package.deb /tmp/extract\n\n# View package contents\ndpkg -c package.deb\n\n# Reconfigure package\nsudo dpkg-reconfigure package-name\nsudo dpkg-reconfigure tzdata        # change timezone\n```\n\n---\n\n## 2. Red Hat/Fedora Package Management (dnf/rpm)\n\n### 2.1 dnf vs yum vs rpm\n\n- **dnf**: Modern package manager (Fedora, RHEL 8+, CentOS 8+)  \n- **yum**: Older package manager (RHEL 7, CentOS 7)  \n- **rpm**: Low-level package tool\n\n### 2.2 Advanced dnf Usage\n\n**Search and info:**\n```bash\ndnf search keyword\ndnf info package-name\ndnf list installed\ndnf list available\ndnf provides /bin/ls               # find package providing file\n```\n\n**Installation:**\n```bash\nsudo dnf install package-name\nsudo dnf install package-name-version.rpm\nsudo dnf reinstall package-name\n\n# Install local RPM\nsudo dnf install ./package.rpm\n```\n\n**Groups (bundles of packages):**\n```bash\ndnf group list\ndnf group info \"Development Tools\"\nsudo dnf group install \"Development Tools\"\nsudo dnf groupremove \"Development Tools\"\n```\n\n**Updates:**\n```bash\nsudo dnf check-update\nsudo dnf update                    # upgrade all\nsudo dnf update package-name       # upgrade specific\n```\n\n**Removal:**\n```bash\nsudo dnf remove package-name\nsudo dnf autoremove                # remove orphaned dependencies\n```\n\n**History:**\n```bash\ndnf history\ndnf history info 5                 # details of transaction 5\nsudo dnf history undo 5            # undo transaction 5\nsudo dnf history rollback 5        # rollback to state before transaction 5\n```\n\n### 2.3 Repository Management\n\n**List repos:**\n```bash\ndnf repolist\ndnf repolist --all\ndnf repoinfo repository-name\n```\n\n**Enable/disable:**\n```bash\nsudo dnf config-manager --enable repository-name\nsudo dnf config-manager --disable repository-name\n```\n\n**Add repository:**\n```bash\nsudo dnf config-manager --add-repo https://example.com/repo/example.repo\n\n# Or manually create /etc/yum.repos.d/example.repo:\n[example-repo]\nname=Example Repository\nbaseurl=https://example.com/repo/\nenabled=1\ngpgcheck=1\ngpgkey=https://example.com/key.gpg\n```\n\n### 2.4 rpm Detailed Usage\n\n```bash\n# Query\nrpm -qa                            # list all installed\nrpm -qi package-name               # package info\nrpm -ql package-name               # list files\nrpm -qc package-name               # list config files\nrpm -qd package-name               # list documentation\nrpm -qf /bin/ls                    # which package owns file\n\n# Install/Upgrade/Remove\nsudo rpm -ivh package.rpm          # install (verbose, show hash)\nsudo rpm -Uvh package.rpm          # upgrade\nsudo rpm -e package-name           # erase (remove)\n\n# Verify\nrpm -V package-name                # verify files haven't changed\n\n# Query package file (not installed)\nrpm -qip package.rpm               # info\nrpm -qlp package.rpm               # list files\n```\n\n---\n\n## 3. Arch Linux Package Management (pacman)\n\n### 3.1 pacman Basics\n\n```bash\n# Sync and update\nsudo pacman -Syu                   # sync repos + full system upgrade\n\n# Install\nsudo pacman -S package-name\nsudo pacman -S package1 package2   # multiple packages\n\n# Remove\nsudo pacman -R package-name        # remove package only\nsudo pacman -Rs package-name       # remove + unused dependencies\nsudo pacman -Rns package-name      # remove + deps + config files\n\n# Search\npacman -Ss keyword                 # search remote repos\npacman -Qs keyword                 # search locally installed\n\n# Info\npacman -Si package-name            # remote package info\npacman -Qi package-name            # installed package info\npacman -Ql package-name            # list files\npacman -Qo /path/to/file           # which package owns file\n\n# List\npacman -Q                          # all installed packages\npacman -Qe                         # explicitly installed\npacman -Qd                         # dependencies\npacman -Qdt                        # orphaned dependencies\n```\n\n### 3.2 AUR (Arch User Repository)\n\nAUR contains community-contributed packages. Need helper like `yay` or `paru`.\n\n**Install yay:**\n```bash\nsudo pacman -S --needed base-devel git\ngit clone https://aur.archlinux.org/yay.git\ncd yay\nmakepkg -si\n```\n\n**Use yay:**\n```bash\nyay -S aur-package-name            # install from AUR\nyay -Syu                           # update everything (repos + AUR)\nyay -Ss keyword                    # search repos + AUR\n```\n\n---\n\n## 4. Compiling from Source\n\n### 4.1 Standard Build Process (./configure, make, make install)\n\n**Step 1: Install build tools**\n\nDebian/Ubuntu:\n```bash\nsudo apt install build-essential\n```\n\nFedora/RHEL:\n```bash\nsudo dnf groupinstall \"Development Tools\"\n```\n\nArch:\n```bash\nsudo pacman -S base-devel\n```\n\n**Step 2: Download source**\n```bash\nwget https://example.com/package-1.0.tar.gz\ntar -xzvf package-1.0.tar.gz\ncd package-1.0\n```\n\n**Step 3: Read documentation**\n```bash\nless README\nless INSTALL\n```\n\n**Step 4: Configure**\n```bash\n./configure --help                 # see options\n./configure --prefix=/usr/local    # set install location\n```\n\nCommon configure options:\n- `--prefix=/path` - where to install\n- `--enable-feature` - enable optional feature\n- `--disable-feature` - disable feature\n- `--with-library=/path` - use specific library\n\n**Step 5: Compile**\n```bash\nmake                               # compile\nmake -j4                           # use 4 CPU cores\n```\n\n**Step 6: Install**\n```bash\nsudo make install                  # install to system\n```\n\n**Uninstall (if supported):**\n```bash\nsudo make uninstall\n```\n\n### 4.2 CMake-based Projects\n\n```bash\n# Create build directory\nmkdir build && cd build\n\n# Configure\ncmake ..\n# Or with options:\ncmake -DCMAKE_INSTALL_PREFIX=/usr/local \\\n      -DCMAKE_BUILD_TYPE=Release ..\n\n# Compile\nmake -j4\n\n# Install\nsudo make install\n```\n\n### 4.3 Managing Build Dependencies\n\n**Debian/Ubuntu - build dependencies:**\n```bash\n# Install build deps for a package in repos\nsudo apt build-dep package-name\n\n# Get source package\napt source package-name\n```\n\n**Checking for missing libraries:**\n```bash\n# During ./configure, if you see:\n# \"error: library XYZ not found\"\n\n# Search for development package:\napt search libXYZ\nsudo apt install libXYZ-dev        # -dev packages have headers\n\n# Example: if configure complains about libssl:\nsudo apt install libssl-dev\n```\n\n### 4.4 checkinstall – Create Package from Source\n\nInstead of `sudo make install`, use `checkinstall` to create a package:\n\n```bash\nsudo apt install checkinstall      # Debian/Ubuntu\n\n# After ./configure && make:\nsudo checkinstall\n\n# This creates a .deb/.rpm that can be managed by package manager\n# Easier to uninstall later\n```\n\n---\n\n## 5. Alternative Package Managers\n\n### 5.1 Snap\n\n```bash\n# Install snapd\nsudo apt install snapd             # Ubuntu\nsudo dnf install snapd             # Fedora\n\n# Usage\nsudo snap install package-name\nsudo snap remove package-name\nsnap list\nsnap find keyword\nsnap refresh                       # update all\n```\n\n### 5.2 Flatpak\n\n```bash\n# Install flatpak\nsudo apt install flatpak\nflatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo\n\n# Usage\nflatpak install flathub app-name\nflatpak run app-name\nflatpak list\nflatpak uninstall app-name\nflatpak update\n```\n\n### 5.3 AppImage\n\n```bash\n# Download .AppImage file\nchmod +x App.AppImage\n./App.AppImage                     # run directly\n\n# No installation needed - self-contained\n```\n\n---\n\n## 6.
