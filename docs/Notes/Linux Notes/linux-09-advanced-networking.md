### 1.2 IPv4 Address Classes & CIDR

**Traditional Classes** (mostly obsolete now):
- Class A: `1.0.0.0` - `126.255.255.255` (8-bit network, 24-bit host)
- Class B: `128.0.0.0` - `191.255.255.255` (16-bit network, 16-bit host)
- Class C: `192.0.0.0` - `223.255.255.255` (24-bit network, 8-bit host)

**CIDR Notation** (modern):\n```\n192.168.1.0/24\n          │   └─ prefix length (24 bits for network)\n          └───── network address\n\nUsable IPs: 192.168.1.1 - 192.168.1.254\nNetwork: 192.168.1.0\nBroadcast: 192.168.1.255\n```\n\nCommon private ranges:\n- `10.0.0.0/8` (10.0.0.0 - 10.255.255.255)\n- `172.16.0.0/12` (172.16.0.0 - 172.31.255.255)\n- `192.168.0.0/16` (192.168.0.0 - 192.168.255.255)\n\n### 1.3 IPv6 Basics\n\nFormat: `2001:0db8:85a3:0000:0000:8a2e:0370:7334`\n\nAbbreviation rules:\n- Leading zeros can be omitted: `2001:db8:85a3:0:0:8a2e:370:7334`\n- Consecutive zeros can be `::` (once): `2001:db8:85a3::8a2e:370:7334`\n\nCommon IPv6 addresses:\n- `::1` - localhost (like 127.0.0.1)\n- `fe80::/10` - link-local\n- `2000::/3` - global unicast\n\n---\n\n## 2. Network Configuration In-Depth\n\n### 2.1 Modern ip Command\n\n**View interfaces:**\n```bash\nip addr show                    # all interfaces\nip -br addr                     # brief format\nip addr show dev eth0           # specific interface\n```\n\n**Add/remove IP addresses:**\n```bash\nsudo ip addr add 192.168.1.100/24 dev eth0\nsudo ip addr del 192.168.1.100/24 dev eth0\n```\n\n**Link control:**\n```bash\nsudo ip link set eth0 up        # bring interface up\nsudo ip link set eth0 down      # bring it down\nsudo ip link set eth0 mtu 1400  # change MTU\n```\n\n**Routing:**\n```bash\nip route show                   # routing table\nip route get 8.8.8.8            # how to reach this IP\nsudo ip route add 10.0.0.0/24 via 192.168.1.1 dev eth0\nsudo ip route del 10.0.0.0/24\nsudo ip route add default via 192.168.1.1  # default gateway\n```\n\n**Neighbor table (ARP):**\n```bash\nip neigh show                   # ARP cache\nip neigh flush dev eth0         # clear ARP for interface\n```\n\n### 2.2 NetworkManager (Desktop/Laptop)\n\nCLI tool:\n```bash\nnmcli device status             # list devices\nnmcli connection show           # list connections\nnmcli con up \"Connection Name\"  # activate\nnmcli con down \"Connection Name\" # deactivate\n\n# Add new connection\nnmcli con add type ethernet con-name eth0-static ifname eth0 \\\n  ip4 192.168.1.100/24 gw4 192.168.1.1\n\n# Modify connection\nnmcli con mod eth0-static ipv4.dns \"8.8.8.8 8.8.4.4\"\nnmcli con mod eth0-static ipv4.method manual\n```\n\n### 2.3 Netplan (Ubuntu Server 18.04+)\n\nConfig: `/etc/netplan/*.yaml`\n\nExample static IP:\n```yaml\nnetwork:\n  version: 2\n  ethernets:\n    eth0:\n      addresses:\n        - 192.168.1.100/24\n      gateway4: 192.168.1.1\n      nameservers:\n        addresses:\n          - 8.8.8.8\n          - 8.8.4.4\n```\n\nApply:\n```bash\nsudo netplan try              # test (auto-revert in 120s)\nsudo netplan apply            # apply permanently\n```\n\n### 2.4 Traditional /etc/network/interfaces (Debian)\n\n```bash\n# /etc/network/interfaces\nauto eth0\niface eth0 inet static\n  address 192.168.1.100\n  netmask 255.255.255.0\n  gateway 192.168.1.1\n  dns-nameservers 8.8.8.8 8.8.4.4\n```\n\nRestart:\n```bash\nsudo systemctl restart networking\n# or\nsudo ifdown eth0 && sudo ifup eth0\n```\n\n---\n\n## 3. DNS Configuration & Troubleshooting\n\n### 3.1 DNS Resolution Files\n\n**/etc/resolv.conf** - DNS servers:\n```bash\nnameserver 8.8.8.8\nnameserver 8.8.4.4\nsearch example.com\n```\n\n**/etc/hosts** - static name resolution:\n```bash\n127.0.0.1       localhost\n192.168.1.100   myserver.local myserver\n```\n\n**/etc/nsswitch.conf** - resolution order:\n```bash\nhosts: files dns\n# Means: check /etc/hosts first, then DNS\n```\n\n### 3.2 DNS Query Tools\n\n**dig (most detailed)**:\n```bash\ndig example.com                 # A record\ndig example.com MX              # mail servers\ndig example.com NS              # nameservers\ndig example.com ANY             # all records\ndig @8.8.8.8 example.com        # use specific DNS server\ndig +short example.com          # brief output\ndig -x 8.8.8.8                  # reverse lookup\n```\n\n**nslookup**:\n```bash\nnslookup example.com\nnslookup example.com 8.8.8.8    # specific server\n```\n\n**host**:\n```bash\nhost example.com\nhost -t MX example.com\n```\n\n### 3.3 systemd-resolved (Modern Ubuntu)\n\n```bash\nresolvectl status               # current DNS config\nresolvectl query example.com    # resolve name\nresolvectl flush-caches         # clear DNS cache\n```\n\nConfig: `/etc/systemd/resolved.conf`\n\n---\n\n## 4. Firewall Management – iptables\n\n### 4.1 iptables Basics\n\n**Chains and Tables:**\n- **filter** table: INPUT, OUTPUT, FORWARD (packet filtering)\n- **nat** table: PREROUTING, POSTROUTING (address translation)\n- **mangle** table: advanced packet modification\n\n**View rules:**\n```bash\nsudo iptables -L                # list all chains\nsudo iptables -L INPUT          # specific chain\nsudo iptables -L -n -v          # numeric, verbose\nsudo iptables -t nat -L         # NAT table\n```\n\n### 4.2 Basic Firewall Rules\n\n**Allow established connections:**\n```bash\nsudo iptables -A INPUT -m conntrack --ctstate ESTABLISHED,RELATED -j ACCEPT\n```\n\n**Allow loopback:**\n```bash\nsudo iptables -A INPUT -i lo -j ACCEPT\n```\n\n**Allow specific ports:**\n```bash\nsudo iptables -A INPUT -p tcp --dport 22 -j ACCEPT          # SSH\nsudo iptables -A INPUT -p tcp --dport 80 -j ACCEPT          # HTTP\nsudo iptables -A INPUT -p tcp --dport 443 -j ACCEPT         # HTTPS\n```\n\n**Allow from specific IP:**\n```bash\nsudo iptables -A INPUT -s 192.168.1.50 -j ACCEPT\n```\n\n**Drop everything else:**\n```bash\nsudo iptables -P INPUT DROP\nsudo iptables -P FORWARD DROP\nsudo iptables -P OUTPUT ACCEPT\n```\n\n### 4.3 Advanced iptables\n\n**Rate limiting (prevent brute force):**\n```bash\nsudo iptables -A INPUT -p tcp --dport 22 -m conntrack --ctstate NEW \\\n  -m recent --set\nsudo iptables -A INPUT -p tcp --dport 22 -m conntrack --ctstate NEW \\\n  -m recent --update --seconds 60 --hitcount 4 -j DROP\n```\n\n**Port forwarding:**\n```bash\n# Forward external port 8080 to internal 192.168.1.10:80\nsudo iptables -t nat -A PREROUTING -p tcp --dport 8080 \\\n  -j DNAT --to-destination 192.168.1.10:80\nsudo iptables -A FORWARD -p tcp -d 192.168.1.10 --dport 80 -j ACCEPT\n```\n\n**Masquerading (NAT for outbound):**\n```bash\nsudo iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE\n```\n\n**Delete rules:**\n```bash\nsudo iptables -D INPUT 3        # delete rule 3 from INPUT\nsudo iptables -F                # flush all rules (DANGER)\nsudo iptables -F INPUT          # flush INPUT chain\n```\n\n### 4.4 Saving iptables Rules\n\n**Debian/Ubuntu:**\n```bash\nsudo apt install iptables-persistent\nsudo netfilter-persistent save\n```\n\n**RHEL/CentOS:**\n```bash\nsudo service iptables save\n# or\nsudo iptables-save > /etc/sysconfig/iptables\n```\n\n**Manual save/restore:**\n```bash\nsudo iptables-save > /etc/iptables.rules\nsudo iptables-restore < /etc/iptables.rules\n```\n\n---\n\n## 5. nftables (Modern Replacement for iptables)\n\n### 5.1 Why nftables?\n\n- Replaces iptables, ip6tables, arptables, ebtables  \n- Simpler syntax  \n- Better performance  \n- Atomic rule updates\n\n### 5.2 Basic nftables\n\n**View rules:**\n```bash\nsudo nft list ruleset\n```\n\n**Example ruleset:**\n```bash\n# /etc/nftables.conf\nflush ruleset\n\ntable inet filter {\n  chain input {\n    type filter hook input priority 0; policy drop;\n    \n    ct state established,related accept\n    iif lo accept\n    tcp dport 22 accept\n    tcp dport { 80, 443 } accept\n  }\n  \n  chain forward {\n    type filter hook forward priority 0; policy drop;\n  }\n  \n  chain output {\n    type filter hook output priority 0; policy accept;\n  }\n}\n```\n\n**Apply:**\n```bash\nsudo nft -f /etc/nftables.conf\nsudo systemctl enable nftables\n```\n\n---\n\n## 6. Network Troubleshooting Methodology\n\n### 6.1 Systematic Approach\n\n**Layer 1-2: Physical/Link**\n```bash\nip link show                    # interface up?\nethtool eth0                    # link detected?\nip -s link show eth0            # check for errors\ndmesg | grep eth0               # kernel messages\n```\n\n**Layer 3: Network/IP**\n```bash\nip addr show                    # have IP address?\nip route show                   # have default route?\nping -c 3 192.168.1.1           # ping gateway\nping -c 3 8.8.8.8               # ping internet\n```\n\n**Layer 4: Transport**\n```bash\nss -tuln                        # listening ports\nsudo ss -tulpn                  # with process names\ntelnet host 80                  # test TCP port\nnc -zv host 80                  # netcat port scan\n```\n\n**Layer 7: Application**\n```bash\ncurl -v http://example.com      # HTTP test\ncurl -v https://example.com     # HTTPS test\nopenssl s_client -connect example.com:443  # SSL test\n```\n\n### 6.2 Common Issues & Solutions\n\n**No IP address (DHCP):**\n```bash\nsudo dhclient eth0              # request DHCP\nsudo dhclient -r eth0           # release\nsudo dhclient eth0              # renew\n```\n\n**DNS not working:**\n```bash\nping 8.8.8.8                    # IP works?\nping google.com                 # DNS works?\ncat /etc/resolv.conf            # correct nameservers?\nsudo systemctl restart systemd-resolved  # restart resolver\n```\n\n**Can't reach service:**\n```bash\nsudo iptables -L INPUT -v -n    # firewall blocking?\nsudo firewall-cmd --list-all    # firewalld check\nss -tulpn | grep :80            # service listening?\nsudo systemctl status httpd     # service running?\n```\n\n### 6.3 Packet Capture with tcpdump\n\n```bash\n# Capture on interface\nsudo tcpdump -i eth0\n\n# Specific port\nsudo tcpdump -i eth0 port 80\n\n# Save to file\nsudo tcpdump -i eth0 -w capture.pcap\n\n# Read from file\ntcpdump -r capture.pcap\n\n# Filter by host\nsudo tcpdump host 192.168.1.100\n\n# Complex filter\nsudo tcpdump -i eth0 'tcp port 80 and src 192.168.1.0/24'\n```\n\nAnalyze with Wireshark:\n```bash\nsudo apt install wireshark\nwireshark capture.pcap\n```\n\n---\n\n## 7.
